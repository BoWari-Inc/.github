# .github

Dépôt public de l'organisation **BoWari** sur GitHub.

Il contient la page de présentation de l'organisation ([`profile/README.md`](profile/README.md)) et a vocation à accueillir les documents communautaires publics.

## Contenu

| Fichier | Rôle |
| --- | --- |
| `profile/README.md` | Présentation affichée sur la page de l'organisation |

## Règles de publication

Ce dépôt est **public**. Tout ce qui y est ajouté est visible de tous.

- Uniquement des informations destinées à être publiées.
- Aucun détail interne : sécurité, infrastructure, architecture détaillée, migration, partenaires non annoncés, éléments commerciaux.
- Aucun secret, aucune donnée personnelle.
- Les capacités de BoWari sont présentées pour ce qu'elles sont : une ambition en construction.

BoWari est un projet de BoWari, Inc., future filiale de GENIUS GROUPS SAS. Aucune licence open source n'est attribuée au contenu de ce dépôt.
